# Projeto-Natural-ou-Fake-Natty - Como entender a IA em três passos

## 📒 Descrição
Este e-book de 3 páginas explana de forma simples e objetiva como entender a IA em três passos

## 🤖 Tecnologias Utilizadas
IA Generativa ChatGPT para roteirização
IA Generativa Leonardo AI para criar a arte visual do e-book
Ferramenta Word para edição

## 🧐 Processo de Criação
Utilizei o "ChatGPT" para revisar minha pesquisa sobre como entender a IA em três passos, estruturar o conteúdo e refinar minhas ideias. Por outro lado, o "Leonardo AI" foi usado para gerar imagens exclusivas para o nosso e-book. Para concluir, a montagem final foi feita no Word, por ser uma ferramenta simples para edição de texto.

## 🚀 Resultados
O e-book apresenta um conteúdo envolvente e visualmente rico, demonstando de forma simples e objetiva como entender a IA em apenas três passos.

## 💭 Reflexão (Opcional)
Criar este e-book foi uma experiência sobre o pontencial criativo das IAs e como elas podem ser aplicadas no cotidiano de forma simples e para várias finalidades.
